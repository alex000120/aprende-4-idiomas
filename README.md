# LinguaMix 4 Idiomas

Aplicación web para aprender español, inglés, chino y japonés a la vez.

## Tecnologías

- React + Vite + TypeScript
- CSS puro (sin costo ni dependencias premium)
- Web Speech API para pronunciación del navegador
- Guardado local con `localStorage`

## Funcionalidades

- Traducción simultánea en 4 idiomas
- Pronunciación con voz del navegador
- Tarjetas de frases y vocabulario útil
- Quiz rápido para reforzar memoria
- Reto diario
- Progreso local y visual
- 100% gratis y listo para subir a GitHub

## Inicio rápido

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

## Despliegue gratis

Puedes desplegar este proyecto en:

- Vercel
- Netlify
- GitHub Pages

Es una app frontend estática, por lo que funciona muy bien sin backend.
